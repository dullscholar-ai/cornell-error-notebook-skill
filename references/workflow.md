# 全流程操作细节

输入是一组扫描件（题卷 + 答卷 / 作业），输出是一份康奈尔错题集。下面按阶段给出动作与判断点。命令里的 `<编号>` 指 `学科-YYYYMMDD-NNN`。

## 阶段 0 · 建档与确认

1. 确定工作目录 `D:/哈哈错题集/<学科>/<YYYY.MM.DD>/`（用户指定优先）。
2. 扫描件命名：题卷用 `题卷1.jpg 题卷2.jpg …`，答卷用 `答卷1.jpg 答卷2.jpg …`，按页序。
3. 从扫描件读出：学科、日期、试卷名称与来源、满分、得分、需要忽略的部分。读不出的问用户，或先记「待确认」。
4. 建 `_w/` 存分析中间件。

## 阶段 1 · 看清版面

```
python scripts/pixel_map.py 答卷1.jpg 0 0 1200 3000 6 6
python scripts/rotate_image.py 题卷1.jpg -1.5 题卷1_fix.jpg
```

先确认哪一块是答题卡格子、哪一块是手写区、哪一块是老师批注，再动手 OCR。

## 阶段 2 · 题卷原文

```
python scripts/ocr_region.py 题卷2.jpg 120 340 1180 760 3
```

把每道错题的题干、全部选项、材料都取出来。公式、图形说明要人工核对。

## 阶段 3 · 判定答卷

```
python scripts/option_scan.py 答卷1.jpg 693 1078 870 1100 4
python scripts/solid_blobs.py 答卷1.jpg 693 1078 870 1100 70 0.42
python scripts/ocr_handwriting.py 答卷1.jpg 130 1140 1050 1200 8
```

对每一道题记录：**我的作答**（以答卷为准）与**正确答案**（以题卷为准）。读不清的标「待确认」。方法见 `ocr-and-judging.md`。

## 阶段 4 · 定「错题清单」

- 错题 = 学生作答与正确答案不一致，或主观题被老师扣分的题。
- 全对的题不写进 `questions`，可放进 `review_ok` 作为「复习追踪」。
- 用户要求忽略的板块（如听力）整块跳过，并在 `notes` 写明。
- 题号顺序按卷面顺序排列。

## 阶段 5 · 逐题写康奈尔内容

每题三栏，标签固定：

- **线索栏**（5 项）：考点 / 关键词 / 规则 / 易错点 / 自测。这一栏是「只看这里就能回忆」的提示，用问句或短语，不要把解法抄进来。
- **主笔记区**（4 段）：① 原题（原文 + 选项，材料与题目之间用 `"————"` 分隔）② 我的作答（照抄学生答案）③ 正确解法（分步写，关键步骤用 ▸ 起头）④ 错因（一句话点破为什么错，不要写「粗心」这种空话）。
- **总结栏**（3 项）：思路归纳（可复用的解题步骤）/ 方法反思（这类题的通用规律）/ 下次提醒（一句能背下来的话）。

写法要点：

- 「④ 错因」要具体到**规则**：不是「算错了」，而是「负数奇次幂符号没记牢」。
- 「③ 正确解法」要让学生能照着复现，含关键中间步骤。
- 「下次提醒」要短、可背，例如「遇到 doesn't / not / except，先用排除法把文中出现过的划掉」。

## 阶段 6 · 汇总页

- `cause_rows`：把错题按**错因类型**归类，写清题号与出现次数，按次数从多到少排。
- `core_issues`：从错因归纳里提炼 **≤3 条**核心问题，每条要点名题号、说清是什么类型的失分。
- `advice`：针对核心问题给可执行的练习动作（专项 + 具体做法 + 数量）。

## 阶段 7 · 生成与交付

```
python scripts/build_notebook.py content.json
python scripts/html_to_pdf.py 英语-20260923-002.html 英语-20260923-002.pdf
python scripts/build_docx.py 英语-20260923-002.html 英语-20260923-002.docx
python scripts/render_pages.py 英语-20260923-002.pdf _pages 100
python scripts/shot_html.py 英语-20260923-002.html _shots 900
```

Word 版面另用 `word_to_pdf.ps1` 导出 PDF 后 `render_pages.py` 看。

## 阶段 8 · 自检清单

- [ ] HTML 含 `<!DOCTYPE html>`、`.cornell-grid`、`.cue-column`、`.summary-column`。
- [ ] 页数 = 1 封面 + 1 索引 + (复习追踪) + N 题 + 1 错因归纳。
- [ ] 每题的线索栏 5 项、主笔记区 4 段、总结栏 3 项齐全。
- [ ] 错题数与索引、判定说明里的数字一致。
- [ ] PDF / Word 一题一页，没有跨页断裂。
- [ ] 交付说明里列出「待确认」的题号。

## 追加与重做

- 追加新卷：新建目录，编号递增，独立生成。
- 修正单题：改 `content.json` 后重跑 `build_notebook.py`；已导出 PDF / Word 的重新导出。
- 只改样式：改 `assets/notebook.css` 后重跑生成脚本。
