# 各学科题型用词与线索栏写法

`sec`（题型）与 `cue` 里「规则」一项随学科变化，其余四栏（考点 / 关键词 / 易错点 / 自测）通用。下面给各学科常用说法，供填写 `content.json` 时选用。

## 语文

- 题型：字音字形、词语运用、病句辨析、古诗文默写、文言文阅读、现代文阅读、名著阅读、综合性学习、作文。
- 线索栏「规则」示例：文言实词要「因文定义」，不能套用现代汉语；病句先找主干再看搭配。
- 关键词常用：原文语句、文言实词、修辞手法名。
- 作文错题：④ 错因写「立意 / 结构 / 语言」哪一层，别写「没写好」。

## 数学

- 题型：选择、填空、计算题、解方程（组）、几何证明、函数与图象、统计与概率、应用题。
- 线索栏「规则」示例：混合运算先乘方再乘除后加减；去括号前是负号要每项变号；证明题每一步都要有依据。
- 关键词常用：公式、定理名、关键条件。公式一律写成 `@@…@@`。
- ④ 错因区分「规则不牢」与「计算失误」，前者才是重点。

## 英语

- 题型：听力（通常按要求忽略）、单项选择、完形填空、阅读理解、短文填空 / 语法填空、任务型阅读、词汇运用、书面表达。
- 线索栏「规则」示例：细节题回原文找依据；遇到 doesn't / not / except 用排除法；名词复数与三单变化看主语。
- 关键词常用：目标单词 / 短语、题干限定词。
- 书面表达：④ 错因分「句式 / 拼写 / 内容点」三类。

## 物理

- 题型：选择、填空、实验探究、作图、计算题。
- 线索栏「规则」示例：先受力分析再列式；单位统一；公式变形后代入数据。
- 关键词常用：物理量符号、公式、单位。公式与符号写成 `@@…@@`。
- ④ 错因区分「概念 / 公式用错」与「单位、有效数字」。

## 化学

- 题型：选择、填空、实验探究、推断题、计算题。
- 线索栏「规则」示例：写化学方程式先配平再标条件与气体/沉淀符号；计算题按「设、写方程式、列比例、解、答」。
- 关键词常用：物质名 / 化学式、反应条件。化学式与方程式写成 `@@…@@`。
- ④ 错因区分「化学式 / 方程式写错」与「概念理解错」。

## 生物

- 题型：选择、填空、识图作答、实验探究、简答。
- 线索栏「规则」示例：识图题按「结构名 → 功能」作答；实验题要控制单一变量、设对照组。
- 关键词常用：结构名称、生理过程名。

## 科学（综合）

- 题型：选择、填空、实验探究、综合计算、简答。
- 线索栏「规则」按题目涉及的物理 / 化学 / 生物 / 地球宇宙分支分别写。

## 历史

- 题型：选择、材料分析题、简答题、论述题。
- 线索栏「规则」示例：材料题「先看设问定方向，再回材料找依据」；论述题要有观点 + 史实 + 结论。
- 关键词常用：时间、事件名、人物、文件 / 条约名。
- ④ 错因区分「史实记错」与「不会用材料」。

## 地理

- 题型：选择、读图分析、填空、简答。
- 线索栏「规则」示例：读图先看图名、图例、经纬度；分析成因按「位置 → 地形 / 气候 → 结果」。
- 关键词常用：地理术语（如 季风、等高线、纬度位置）。

## 社会 / 道德与法治

- 题型：选择、材料分析、辨析、简答、实践探究。
- 线索栏「规则」示例：材料分析按「材料关键句 → 对应知识点 → 结合材料作答」；辨析题先判断再说明理由。
- 关键词常用：核心概念、政策 / 法律名称。

## 通用提醒

- `star` 按「学生实际失分难度」给：概念没懂 ★★★，规则没记牢 ★★，纯粹看错 / 抄错 ★。
- 同一份卷里，**同一类错因**尽量用同一套措辞，方便 `cause_rows` 归类统计。
