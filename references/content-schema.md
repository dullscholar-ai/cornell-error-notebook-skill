# content.json 字段说明

`build_notebook.py` 只认这个结构。除 `subject` 与 `questions` 外，字段都可省略。

## 顶层字段

| 字段 | 必填 | 说明 |
|:--|:--|:--|
| subject | 是 | 学科名，如 英语 / 数学 / 物理 / 历史 |
| date | 建议 | `YYYY-MM-DD` |
| code | 建议 | 编号，同时用作输出文件名，如 `数学-20260923-001` |
| class_name | 否 | 班级，如 `709`（显示为「709 班」） |
| grade_line | 否 | 封面副标题前缀，如 `七年级上` |
| source | 否 | 试卷名称与来源 |
| total / score | 否 | 满分 / 得分 |
| notes | 否 | 字符串数组；写在封面与索引页的说明（如「听力部分按要求忽略」） |
| judge_heading | 否 | 判定依据说明的标题，默认「〇、判定依据说明（先看这一段）」 |
| judge_note | 否 | 字符串数组，替换默认的三重交叉验证说明；以 `1. ` 这类序号开头的行渲染成有序列表 |
| questions | 是 | 错题数组，见下 |
| review_ok | 否 | `[["31","D","D"], …]`（题号, 我的作答, 正确答案）；填了就多一页「复习追踪」 |
| cause_rows | 否 | `[["错因类型","题号",次数], …]` |
| core_issues | 否 | 字符串数组，核心问题（建议 ≤3 条） |
| advice | 否 | 字符串数组，学习建议 |
| correction_box | 否 | 默认 `true`：每题页底部生成「订正区」空白书写框（约 1/3 页高、贴页底） |
| correction_box_height | 否 | 订正区高度，默认 `"88mm"`；改小如 `"60mm"` |

## questions 每一项

| 字段 | 说明 |
|:--|:--|
| q | 题号，字符串 |
| sec | 题型 / 板块，如 完形填空、材料分析题、计算题 |
| topic | 考点，一句话 |
| star | 难度，`★` / `★★` / `★★★` |
| src | **出处**（建议必填）：`材料 + 页码/题号 + 扫描件文件名 + 位置`，如 `"题题清练习册 B12 页 第 1 题 ｜ 扫描件 IMG_20261002_135120.jpg（左栏）"`；渲染在题目页题头下方灰条和错题索引表「出处」列，方便回到原始试卷人工比对 |
| images | **配图**：字符串数组，相对 HTML 的路径（如 `figures/fig_b12_q1.jpg`），嵌在「① 原题」下方；同一张图被多道小题引用时复用同一文件。配图需先经 `whiten_figs.py` 拉白纸底 |
| cue | 线索栏，5 项：`[["考点","…"],["关键词","…"],["规则","…"],["易错点","…"],["自测","…"]]` |
| body | 主笔记区，4 段：`[["① 原题",[…] ],["② 我的作答",[…] ],["③ 正确解法",[…] ],["④ 错因",[…] ]]` |
| summ | 总结栏，3 项：`[["思路归纳","…"],["方法反思","…"],["下次提醒","…"]]` |

约定：

- `body` 里单独一行写 `"————"` 会渲染成一条分隔线（用来把「材料」与「题目」分开）。
- 行内标记：`**加粗**`；`@@等宽@@`（英文单词、公式、规则名、选项字母）。
- 线索栏 5 项、主笔记区 4 段、总结栏 3 项的标签沿用默认名，跨学科统一，方便复习时只看线索栏回忆。

## 完整示例（数学，1 道题）

```json
{
  "subject": "数学",
  "grade_line": "七年级上",
  "class_name": "709",
  "date": "2026-09-23",
  "code": "数学-20260923-001",
  "source": "七年级上 第二章 有理数及其运算 单元测评（时间 90 分钟）",
  "total": "100",
  "score": "82",
  "notes": ["本次未收录第 1—8 题（选择题，全对）。学生实际作答以答卷为准。"],
  "questions": [
    {
      "q": "18",
      "sec": "解答题",
      "topic": "有理数混合运算 · 运算顺序与符号",
      "star": "★★",
      "src": "××卷 第 18 题（解答题）｜ 扫描件 IMG_20260923_101.jpg（第 2 页，单栏通排）",
      "images": ["figures/fig_q18.jpg"],
      "cue": [
        ["考点", "含乘方、除法、加减的混合运算，先算乘方，再算乘除，最后算加减"],
        ["关键词", "@@(-2)^3@@、@@÷(-1/2)@@、去括号变号"],
        ["规则", "同级运算从左到右；括号前是负号，去括号后每一项都变号"],
        ["易错点", "把 @@(-2)^3@@ 算成 @@8@@（漏掉负号）；去括号只变了第一项"],
        ["自测", "@@(-2)^3@@ 等于多少？去括号时负号要作用到几项？"]
      ],
      "body": [
        ["① 原题", ["计算：@@(-2)^3 ÷ (-1/2) + (-6) × (1/3 - 1/2)@@", "————", "（要求写出必要的运算步骤）"]],
        ["② 我的作答", ["@@= 8 ÷ (-1/2) + (-6) × (-1/6)@@", "@@= -16 + 1 = -15@@"]],
        ["③ 正确解法", ["▸ @@(-2)^3 = -8@@（负数的奇次幂为负，这一步先算）", "@@-8 ÷ (-1/2) = -8 × (-2) = 16@@", "@@(1/3 - 1/2) = -1/6@@，@@(-6) × (-1/6) = 1@@", "▸ 原式 @@= 16 + 1 = 17@@"]],
        ["④ 错因", ["▸ 第一步 @@(-2)^3@@ 误算为 @@8@@，导致后面全错；这是符号规则没记牢，不是计算粗心"]]
      ],
      "summ": [
        ["思路归纳", "① 先扫一遍有哪几级运算 → ② 乘方单独算出结果 → ③ 除法转乘法 → ④ 最后加减"],
        ["方法反思", "负数的奇次幂是负数、偶次幂是正数，这一步必须单独写出来，不能心算。"],
        ["下次提醒", "看到 @@(-a)^n@@ 先在旁边写结果再往下算；去括号时用箭头指到每一项。"]
      ]
    }
  ],
  "review_ok": [["1", "C", "C"], ["2", "A", "A"], ["5", "D", "D"]],
  "cause_rows": [
    ["有理数符号（乘方、去括号）规则不牢", "18、21", 2],
    ["混合运算顺序出错", "18", 1],
    ["应用题不列式直接估算", "23", 1]
  ],
  "core_issues": [
    "**符号规则是本卷最集中的失分点。** 18、21 两题都是「方法会、符号错」，属于可以靠规则默写补上的失分。",
    "**运算顺序依赖心算。** 18 题第一步就跳步，说明没有「先写一步再算下一步」的习惯。"
  ],
  "advice": [
    "**符号规则默写**：负数的奇次幂 / 偶次幂、去括号变号、除法转乘法三组规则各默写 5 例。",
    "**分步书写**：每道计算题强制一步一行，禁止跳步；写完回代验算一次。",
    "**应用题专项**：先写「设」「列」「解」「答」四步框架，再往里填数。"
  ]
}
```

## 输出结构（生成的 HTML）

1. 封面（`.page.cover`）
2. 错题索引 + 判定依据说明
3. 复习追踪（仅当有 `review_ok`）
4. 每题一页：`.question-block` → `.cornell-grid`（`.cue-column` + `.main-column`）→ `.summary-column`
5. 错因归纳 + 核心问题 + 学习建议

每页固定 210mm × 297mm，`page-break-after: always`，所以导出的 PDF / Word 一题一页。
